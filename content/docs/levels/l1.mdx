# L1 · 单表应用

## 级别定位

L1 是活字格能力体系中的**入门级**。掌握本级别后，您可以独立完成基于单张数据表的录入与展示类应用，例如客户邀约登记、满意度调查等轻量级场景。

- **典型场景**：单表数据的增删改查、简单表单填报、基础信息展示
- **团队角色**：适合个人开发者快速搭建工具型应用
- **推荐学习时长**：具备 IT 背景约 **4 小时**

## 推荐教程

**【推荐】**结合以下官方资源进行学习，可快速入门：

- [活字格官方帮助文档](https://www.grapecity.com.cn/solutions/huozige/help/docs/overview) —— 平台功能与操作的基础说明
- 葡萄城学堂提供的入门级 e-Learning 课程与直播回放

## 核心技能清单

本级别共 **9 项**核心技能，涵盖页面设计、数据表操作、基础命令与发布流程。

### 页面与数据表

**`A-1` 创建工程与页面**
掌握活字格工程的创建方法，能够新建页面并理解「设计器」的基本工作区结构。

**`A-2` 数据表设计**
掌握「内建表」的创建方法，能够设计字段（文本、数字、日期等基础类型），理解主键与字段属性。

**`A-3` 单表数据绑定**
能够将页面元素与数据表进行绑定，实现数据的录入与展示。这是 L1 级别最核心的能力。

### 交互与命令

**`B-1` 基础命令**
掌握「设置单元格值」「弹出页面」「关闭页面」等基础命令的使用，实现简单的页面交互。

**`B-2` 数据命令**
掌握「新增行」「更新行」「删除行」等数据操作命令，完成单表数据的基本增删改。

**`B-3` 公式与表达式**
理解单元格公式与表达式的写法，能够完成简单的计算与数据显示逻辑。

### 发布与运行

**`C-1` 应用发布**
掌握将工程发布到服务器的方法，理解「设计器」与「运行时」的区别。

**`C-2` 用户与权限基础**
了解活字格内置的用户体系，能够为应用配置基本的访问用户。

**`C-3` 调试与预览**
掌握在「设计器」中预览与调试页面的方法，能够在开发过程中验证功能。

<Callout title="L1 学习提示">

L1 的重点是建立对活字格「设计即实现」理念的整体认知。**不必追求复杂业务逻辑**，应聚焦于打通「设计页面 → 绑定数据 → 发布运行」的完整链路。本级别的应用通常不涉及多表关联与服务端命令。

</Callout>

## 实战检验

完成 L1 学习后，建议独立完成一个**单表填报类小应用**作为检验，例如：

- 客户邀约信息登记表
- 活动满意度调查问卷

要求覆盖：新建工程、设计页面、绑定数据表、实现录入与列表展示、发布应用。
