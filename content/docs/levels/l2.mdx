# L2 · 数据填报与展示应用

## 级别定位

L2 是活字格能力体系中的**进阶级**。掌握本级别后，您可以独立完成涉及多表关联、数据查询与展示、审批流程的中等复杂度应用，例如在线工单、在线预约等业务场景。

- **典型场景**：多表关联的填报与查询、列表与图表展示、简单审批流、报表导出
- **团队角色**：可承担中小型业务应用的主力开发
- **推荐学习时长**：具备 IT 背景约 **24 小时**

## 核心技能清单

本级别共 **12 项**核心技能，涵盖多表关联、查询展示、工作流、图表与报表。

### 多表与关联

**`A-4` 多表关联设计**
掌握「外键关联」与「关联表」的设计方法，能够建立主从表关系，实现跨表数据联动。

**`A-5` 视图与查询**
掌握「视图」的创建与使用，能够基于多表构建查询结果集，支撑列表页的数据展示。

**`A-6` 数据导入导出**
掌握数据的批量导入与导出能力，能够在初始化与日常运维场景中迁移数据。

### 展示与交互

**`B-4` 列表与分页**
掌握列表页的设计与分页、排序、筛选能力，能够高效展示中等规模数据。

**`B-5` 图表展示**
掌握图表组件的使用，能够以柱状图、折线图、饼图等形式可视化业务数据。

**`B-6` 主从页面联动**
掌握主表与从表（明细）页面的联动设计，实现「选择主记录 → 查看 / 编辑明细」的典型交互。

**`B-7` 表单校验**
掌握必填、格式、范围等表单校验能力，保障录入数据的准确性与完整性。

### 流程与报表

**`C-4` 工作流基础**
掌握「审批流程」的配置方法，能够搭建包含提交、审批、驳回的简单审批流。

**`C-5` 消息通知**
掌握流程节点与系统事件触发的消息通知能力，实现任务待办与状态提醒。

**`C-6` 报表设计**
掌握报表的设计与导出能力，能够生成符合业务规范的打印 / 导出报表。

**`C-7` 打印与输出**
掌握页面与报表的打印输出配置，满足线下单据、凭证的输出需求。

### 协作与版本

**`D-1` 版本管理基础**
了解活字格内置的「版本管理」机制，能够在开发过程中保存历史版本、进行版本对比。

<Callout type="warn" title="L2 重点提醒">

L2 是从「能用」迈向「能交付」的关键过渡。本级别的应用开始涉及**多表关联与流程**，业务逻辑显著复杂化。建议在实战中重点打磨**数据模型设计**与**查询性能**，避免在列表页拉取过多关联数据，为后续 L3 的服务端命令架构打好基础。

</Callout>

## 实战作业

完成 L2 学习后，官方推荐以《**设备巡检系统**》作为实战检验项目，综合运用多表关联、列表查询、审批流程与报表导出能力。建议覆盖：

- 设备台账（主表）与巡检记录（从表）的关联设计
- 巡检任务的列表展示与分页查询
- 巡检结果的审批流程
- 巡检报告的导出与打印
