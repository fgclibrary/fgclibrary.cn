PDA 页面以**简洁实用、操作清楚、运行稳定**为目标。本章面向使用活字格开发 PDA 应用的工程师，先介绍设计原则与最佳实践，再用同一个采购入库 Demo 说明这些原则如何落实到页面和操作中。

建议按以下顺序学习：**理解原则 → 对照业务场景 → 观察操作效果 → 在设计器中查看实现**。

## 五项设计原则

| 章节 | 设计重点 |
| --- | --- |
| [任务与场景定义](/docs/solutions/hac/principles/goals-scenarios) | 先明确谁在什么环境下完成什么任务，再确定页面内容、操作流程和离线需求。 |
| [信息架构](/docs/solutions/hac/principles/information-architecture) | 一个页面一个重点，按核对和操作顺序组织信息，编辑对象与保存结果始终对应。 |
| [交互行为](/docs/solutions/hac/principles/interaction-behavior) | 减少重复输入，区分编辑与业务操作；每次操作有反馈，失败后保留数据并允许继续。 |
| [视觉可读性](/docs/solutions/hac/principles/visual-perception) | 字号与按钮适合小屏操作，布局跟随实际视口；主题统一，关键数据突出，状态配合文字和图标。 |
| [性能与稳定性](/docs/solutions/hac/principles/performance) | PDA 数据展示使用图文列表，禁止直接使用活字格表格；合理加载数据，减少复杂组件和图片，保护作业结果。 |

五篇都先讲原则，再结合 Demo 解释设计做法。字号与按钮尺寸、自适应布局、超过 50 条数据时的加载设置等具体建议，在对应文章中展开。

## 贯穿本章的采购入库案例

模拟场景是一座位于偏远园区的工厂仓库：管理员使用 PDA 核对到货物料并录入数量，现场移动网络较弱，部分区域无信号。因此，页面需要方便查找订单、核对物料和修改数量，也要支持离线录入与恢复在线后的同步。

Demo 的主要流程为：

**登录 → 进入采购入库 → 筛选或查找订单 → 核对物料 → 修改数量 → 检查接收结果**。

遇到无信号区域时，在约定范围内切换到离线模式记录数量，恢复在线后同步。页面以图文列表、清楚的文字和直接的按钮操作为主，具体设计分别对应前面的五项原则。

最终演示包含在线数量从 `50/100` 更新为 `55/100`，以及离线保存 `10/100` 后切回在线显示同步成功。**“保存修改”和“接收货品”是两个独立动作**，学习时应同时查看页面反馈和对应的命令逻辑。

## 获取 Demo 到本地设计器

本章使用的 Demo 已放在 **Gitee 码云仓库**，可拉取到本地活字格设计器中，查看页面布局、数据绑定、事件命令和业务逻辑编排。

[打开采购入库 Demo 仓库](https://gitee.com/erikxue/pda-desgin-demo-purchasing-warehousing)

工程版本为 **12.0.3.0**，建议使用相同版本的活字格设计器打开。获取步骤如下：

1. 启动活字格设计器，在功能区选择【协同】→【打开工程】。
2. 在打开协作工程的对话框中，填入下方仓库地址。
3. 刷新分支列表并选择 `master` 分支，点击【确定】，等待工程拉取并打开。如出现远程服务器认证提示，按提示使用有访问权限的 Gitee 账号完成认证。
4. 打开后，在左侧对象管理器中查看页面、数据表与服务端命令，按下表的页面名称定位具体设计。

仓库地址：

https://gitee.com/erikxue/pda-desgin-demo-purchasing-warehousing.git

## 在 Demo 中查看什么

打开工程后，可按作业顺序查看以下页面和命令，将文档中的原则与实际配置对应起来：

| 页面或命令 | 学习重点 |
| --- | --- |
| `Home` | 业务入口如何组织，如何进入采购入库。 |
| `POList` | 订单搜索与状态筛选、图文列表的数据绑定及加载设置、进入详情时的参数传递。 |
| `PODetails` | 物料信息与操作的排列、数量编辑入口、接收校验、在线与离线模式切换。 |
| `Popup-Quality` | 当前物料信息的传入、数量加减、“保存修改”的命令编排和结果回显。 |
| 服务端命令“提交离线模式保存数据” | 对照页面调用，查看离线记录提交时的参数和数据处理逻辑。 |

查看某个操作时，先选中对应按钮或单元格，查看其事件与命令，再沿着页面参数、数据绑定和服务端命令继续阅读。**具体的页面设计和逻辑编排以 Demo 工程为学习入口**；应用到自己的项目时，再按实际业务规则、设备和网络条件调整与验证。

本章演示使用的 HAC 版本为 **v1.22.0-release**。需要在 PDA 上体验扫码、离线等功能时，可结合[安装与配置](/docs/solutions/hac/installation)和[功能用法](/docs/solutions/hac/features)完成环境准备。
