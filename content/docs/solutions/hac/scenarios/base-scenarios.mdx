---
title: 基础场景
description: HAC 的基础能力可以支撑哪些现场业务场景。
---

HAC 通过插件命令开放扫码、定位、NFC、BLE、拍摄、离线存储等设备能力。单项能力解决一个具体动作，多项能力组合起来，就能支撑完整的现场作业。

| 基础场景 | 用到的能力 |
| --- | --- |
| 收货、拣货、复核 | 扫描 |
| 资产盘点、托盘识别 | 扫描（UHF / RFID） |
| 设备巡检、工位确认 | 扫描、NFC |
| 现场签到、巡检打卡 | 定位 |
| 拍照取证、入库验收 | 拍摄 |
| 传感器采集、设备控制 | BLE |
| 作废、放行、高价值出入库 | 生物识别认证 |
| 戴手套、单手连续作业 | 物理按键监听 |
| 弱网、无网现场作业 | 离线存储 |

每项能力的详细说明与配置见[插件功能列表](/docs/solutions/hac/features/command-index)。

把多项能力组织成完整业务流程的方式，可参考[离线填报](/docs/solutions/hac/scenarios/offline-form)。
