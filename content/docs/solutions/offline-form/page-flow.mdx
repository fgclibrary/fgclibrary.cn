本节给出可直接参考的页面编排示例。实际项目中的命令与设计器能力名称，与[构建离线表单](/docs/solutions/offline-form/build-form)、[下发到 HAC](/docs/solutions/offline-form/download-form)和[回传填报数据](/docs/solutions/offline-form/upload-form)文档保持一致。

## 在线下载或更新页面

这张页面在用户联网时打开，用于把表单定义下发到设备，或在表单定义更新后替换设备上的旧项目。

1. 使用“构建离线页面内容”命令配置步骤页面内容，并将结果返回到变量，例如 `OfflineFormItem`。
2. 使用“构建离线表单”命令填写 `项目编号`、`名称`、`描述`、`版本号` 和 `步骤`。若某一步的内容来自上一步变量，将该步骤的“使用页面内容公式”设为 `true`，并在“页面内容公式”中引用对应变量；最后将完整 JSON 返回到 `OfflinePatternJson`。
3. 使用“检测离线表单 JSON”命令，输入 `OfflinePatternJson` 并校验。结果为无效时，读取错误变量修正表单定义后再下载。
4. 使用“下载离线表单”命令，将 `离线表单JSON` 设置为 `OfflinePatternJson`。异步命令通过 `IsSuccess` 与 `Error` 提示用户下载结果。
5. 如需在设备上展示说明文档，使用“下载离线表单说明 PDF”命令，`项目编号` 填写与 Pattern 根字段 `patternId` 一致的编号，`说明 PDF 附件` 填写服务器上的说明 PDF 附件路径，也可指定页面单元格获取。

## 在线回传或数据维护页面

这张页面在用户恢复网络后打开，用于选择设备项目、回传填报数据，并在确认入库后清理设备。

1. 使用“上传离线表单”命令并选择“获取设备上的离线表单项目编号列表”，获取并展示设备上的表单项目编号。
2. 用户选择单个项目后，在同一命令中选择“导出离线表单数据”并填写 `项目编号`，将记录导出到“导出结果”；多项目场景可选择“批量导出离线表单数据”，不需要填写 `项目编号`。
3. 由服务端命令解析“导出结果”并完成业务写表，附件临时文件标识在该步骤完成正式归属。
4. 写表成功后，使用“上传离线表单”命令中的“标记离线记录已导出”，按需传入 `记录编号`，将记录标记为已导出。
5. 确认数据已安全落库后，使用“删除已读离线记录”清理已读记录；确认整个项目不再需要时，再使用“删除离线表单项目”删除项目。

## 页面编排提示

- 两张页面建议分开，下载页面负责“把表单给设备”，回传页面负责“把数据拿回来”。
- 导出、标记、删除都通过同一个“上传离线表单”命令实现，建议在回传页面按动作拆分按钮，避免一次执行过多能力。
- 异步命令的 `IsSuccess` 与 `Error` 要接到页面提示上，让现场人员能判断“下载完成”“附件过多”“未设置上传限制”等结果。
- 批量导出虽然一次返回多个项目，仍需分别按 `projectId` 找到对应表单定义后再写表。
