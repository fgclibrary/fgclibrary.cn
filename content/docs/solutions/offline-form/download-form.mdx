构建与校验完成后，需要用户在**联网状态**下进入活字格页面，把表单项目保存到 HAC。本节涉及“下载离线表单”和“下载离线表单说明 PDF”两个命令。

这两个命令都支持异步。异步命令默认提供两个隐藏异步结果变量：

- `IsSuccess`：操作是否成功。
- `Error`：失败时的错误信息。

页面可以利用这两个变量提示用户，或继续执行后面的命令。

## 下载离线表单命令

命令名称：**下载离线表单**。

作用：将“构建离线表单”命令生成的 Pattern JSON 下载到设备端，保存为设备上的离线表单项目。命令支持异步，通过隐藏异步结果变量 `IsSuccess` 与 `Error` 触发后续动作。

命令参数：

| 参数 | 说明 |
| --- | --- |
| `离线表单JSON` | 通常使用“构建离线表单”命令生成的 JSON，必填。 |

命令执行行为：

1. 先解析并校验离线表单 JSON；校验失败时提示错误，不执行下载。
2. 为每个表单项补充 `updateTime`。
3. 调用 HAC 下载离线表单项目并保存在本地。
4. 完成后通过 `IsSuccess` 与 `Error` 触发后续异步命令。

## 下载离线表单说明 PDF

命令名称：**下载离线表单说明 PDF**。

作用：将一个或多个说明 PDF 下载到设备，并绑定到指定的离线表单项目，通常用于说明文档节点。

命令参数：

| 参数 | 说明 |
| --- | --- |
| `项目编号` | 要绑定说明 PDF 的离线表单项目编号，必填。 |
| `说明 PDF 附件` | 传入服务器上的说明 PDF 附件路径，必填。命令会根据路径自动获取附件资源，也支持指定页面单元格获取。 |

附件路径支持使用英文竖线 `|` 分隔多个附件标识，例如 `fileA|fileB|fileC`。命令会将每个附件标识转换为下载地址并逐个下载，全部完成后才触发成功回调。
