# 工程扩展

## 结构

**【推荐】**应用工程中的所有对象，建议按照功能模块进行分组构建对象目录树。

<Callout>

按照功能模块分组可以较为方便的配合权限模块进行配置，也便于后续的模块拆分。

</Callout>

## 插件

**【推荐】**升级活字格设计器时，请关注官方插件的版本，将其同步升级。

<Callout>

活字格版本升级时，官方插件会同步升级，增加新特性并修复问题。

</Callout>

*【参考】*插件可以很方便地解决一些难题。葡萄城市场是获取插件的有效途径。如果您的开发场景涉及到较多的自定义逻辑，团队具备插件开发能力会有效提升开发效率。
